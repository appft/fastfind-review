# FastFind 体验评测：高效的Windows文件检索工具
最近在寻找一款本地文件检索工具，尝试了FastFind，整体使用感受很不错。对比大家熟知的Everything，FastFind除了文件名检索之外，还支持搜索PDF、Office文档内的文本内容，这一点在查找大量资料文档时非常实用。

软件提供了3个版本：安装版、便携版以及Pro远程测试版。安装版适合长期固定电脑使用，支持开机后台维护文件索引；便携版为单文件，免安装，可以放在U盘直接运行，不留系统痕迹。Pro版本最大亮点是远程Web访问功能，在外网通过浏览器就可以搜索家里电脑上的文件，附带远程文件预览、下载，还支持WOL远程开机，刚好适合我这种搭建了iKuai路由器+IPv6公网DDNS的家庭网络环境，远程调取本地文件很方便。

程序本体体积很小，仅几MB，索引建立速度快，资源占用低，普通用户安装无需管理员权限。软件官网：https://fastfind.kr
验证码：FF-UCAQE6

在实际使用中，索引更新比较及时，搜索响应迅速。远程功能是我最看重的特性，外出时不用远程桌面，直接网页检索电脑文件。整体来说是一款很有特色的文件搜索工具。
